# 다락 Darak — 3층 AI 워크스페이스 (디자인 초안)

뉴스·수업·일·서재·가족이 함께 사는 3층짜리 작은 집으로 설계한 1인용 메타버스 워크스페이스의 **디자인 초안**입니다.

- **1층** 거실·응접실(수납장 런처) · 뉴스 라운지 · with JF · 정원
- **2층** 교실(성취기준 MCP 연계) · 방탈출 · 작업실
- **3층** 서재(작품·독서·여행 지도) · 루프탑 수영장 · 캠핑 데크

## 보기

GitHub Pages로 배포됩니다: Settings → Pages → Branch `main` / `/ (root)`.
로컬에서는 `index.html`을 브라우저로 열면 됩니다(빌드 없음).

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 (집 둘러보기 · 뉴스 라운지 · 계획 · 이름 후보) |
| `styles.css` | 디자인 토큰(낮/밤 테마)과 스타일 |
| `app.js` | 방 열기, 수납장 런처, 뉴스 필터 등 인터랙션 |

화면의 모든 데이터는 예시입니다. 설계는 「개인 AI 워크스페이스 구축 가이드」(2026)의 10단계 구조를 따릅니다.
